# Day 3：デザイン基盤

## 基本方針

- 親しみやすい青を主役に、白い面と明るい黄色のアクセントを使う。
- 完全初心者が読みやすい日本語ゴシック体と、余裕のある行間を優先する。
- LPはモバイル優先、無料体験は同じDOM順からPCの2列へ展開できる基盤にする。
- 視覚効果より、WCAG 2.2 AAのコントラスト、明確なフォーカス、200％拡大時の操作性を優先する。

## デザイントークン

### 色

| 用途 | 値 | 使用方針 |
| --- | --- | --- |
| Primary | `#2563EB` | 主CTA、主要な強調 |
| Primary Dark | `#1D4ED8` | ホバー、リンク、淡色背景上の文字 |
| Accent | `#FACC15` | ロゴや装飾。白文字の背景には使わない |
| Text | `#0F172A` | 本文と黄色背景上の文字 |
| Sub Text | `#475569` | 補足文。白／淡色背景で使用 |
| Background | `#F8FAFC` | ページ背景 |
| Surface | `#FFFFFF` | カード、ヘッダー、フッター |
| Success | `#15803D` | 正解。文字やアイコンも併用する |
| Error | `#B91C1C` | 誤答。文字やアイコンも併用する |
| Focus | `#2563EB` | 3pxアウトライン |

`Primary`と白、`Text`と白、`Sub Text`と白は通常文字でAAを満たす組み合わせとして採用する。状態表示は色だけに依存しない。

### 文字

- 本文：16px相当、行間1.75。
- 小さい補足：14px相当。主要操作や重要説明には使わない。
- 見出し：`clamp()`で拡大し、固定ブレークポイントを増やさない。
- 日本語：Hiragino Sans、Yu Gothic、Noto Sans JP、sans-serifの順。外部Webフォントは読み込まない。
- コード：OS標準の等幅フォント。体験画面で使用する。

### 余白・形・影

- 余白は4、8、12、16、24、32、48、64px相当の段階を使う。
- 角丸は8、12、16px。ボタン12px、カード16pxを基本とする。
- 影は情報階層の補助に限定し、カードは枠線と弱い影を併用する。
- コンテンツ最大幅は1120px、左右余白は16〜32pxで可変にする。
- 操作領域は44px以上を共通トークンで確保する。

## 共通コンポーネント

- `.c-button`：主・副・無効状態。リンクとボタンで同じ見た目を再利用する。
- `.c-card`：特徴、ロードマップ、料金、学習内容の共通面。
- `.c-section-heading`：補助ラベル、見出し、導入文。
- `.p-site-header`：ロゴと主要操作の土台。完全なLPナビゲーションはDay 4・6で追加する。
- `.p-site-footer`：サービス名、コピーライト、架空デモ注記。
- `.l-container`／`.l-section`：最大幅と共通セクション余白。
- `.u-visually-hidden`：視覚表示せず読み上げる補助文。

## フォーカスと動き

- すべてのフォーカス可能要素に青3px、3pxオフセットの`:focus-visible`を表示する。
- ボタンは背景色だけでなく輪郭と文字でも状態を識別できるようにする。
- `prefers-reduced-motion: reduce`ではスムーズスクロールとトランジション時間を無効化する。
- Day 6のフェードイン実装でもこの動き軽減設定を引き継ぐ。

## アイコン・イラスト方針

- シンプルなフラット表現に統一し、青・淡い青・黄色・濃紺を中心にする。
- アイコンは線幅と角の丸みを揃え、単独で意味を伝える必要がある場合はテキストラベルを添える。
- 装飾だけの図は`aria-hidden="true"`または空の代替テキスト、情報を持つ画像は内容が分かる代替テキストを付ける。
- ファーストビューのイラストと学習画面モックはDay 4、各セクション用素材はDay 5で必要性を判断する。
- 外部画像やアイコンライブラリは追加せず、必要な素材は軽量なプロジェクト内アセットとして管理する。
