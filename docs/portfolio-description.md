# ポートフォリオ掲載用説明文

## 短文版

プログラミング完全初心者向けの架空Java学習サービス「はじめてJava」を制作しました。サービス紹介LPに加え、コード入力、正誤判定、誤答別ヒント、解説、進捗保存を備えた全3問の無料体験を実装しています。Java研修のサブ講師経験を生かし、学ぶ順番に迷わない情報設計と、やさしい言葉で理解できる学習体験を意識しました。

## 詳細版

### 制作概要

「はじめてJava」は、これからJavaを学び、ITエンジニアを目指すプログラミング完全初心者を想定した架空の学習サービスです。「何から学べばよいか分からない」「環境構築でつまずく」という課題に対し、6段階のロードマップとブラウザ上の無料体験を設計しました。

### 工夫した点

- LPから無料体験まで一貫したユーザー導線
- 「一部入力→1行入力→表示内容変更」と段階的に進む全3問
- 誤答内容に応じたヒントと初心者向け解説
- `localStorage`による入力内容と進捗の保存・自動再開
- キーボードショートカット、フォーカス移動、読み上げ、動き軽減への対応
- VitestとPlaywrightによる回答判定・保存・主要導線の自動テスト
- GitHub Pagesのプロジェクトサイトを考慮した静的配信

### 制作経験とのつながり

Java／Spring Bootを使ったWebアプリケーション開発経験と、新入社員向けJava研修でサブ講師として質問対応、エラーの一次切り分け、進捗・理解度の記録を担当した経験を、初心者向けの文章、段階的な問題、誤答時のヒント設計へ反映しています。

### 使用技術

HTML／SCSS／JavaScript（ES Modules）／Vite／Vitest／Playwright／axe／GitHub Actions／GitHub Pages
